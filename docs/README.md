# Описание системы

Keitaro Wrapper — простой интерфейс поверх трекера Keitaro. Он умеет две вещи:

1. [Создать кампанию](campaign-create.md) в пару кликов: трафик из выбранной страны уходит на
   Google, остальной — на выбранный оффер.
2. [Редактировать офферы в потоках](campaign-editor.md) существующей кампании: добавлять,
   удалять, возвращать офферы и закреплять их доли. Изменения сначала видны только в обёртке и
   попадают в Keitaro по кнопке **Push to KT**.

## Термины

- **Поток** — правило внутри кампании Keitaro, которое решает, куда отправить посетителя.
- **Оффер** — страница, на которую поток отправляет посетителя.
- **Доля** — процент трафика потока, который получает оффер. Сумма долей в потоке — 100 %.
