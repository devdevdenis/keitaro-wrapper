# Описание системы

Keitaro Wrapper — простой интерфейс поверх трекера Keitaro. Он умеет:

1. [Показывать кампании трекера](campaigns.md) — с поиском и страницами — и удалять их
   (кампания уходит в архив Keitaro).
2. [Создать кампанию](campaign-create.md): указать название, домен, группу и источник — потоки
   добавляются уже в редакторе, из готовых шаблонов. Параметры можно поменять и потом.
3. [Редактировать потоки кампании](campaign-editor.md): страны и редирект перехватывающего потока, офферы и их доли в обычном потоке, добавление и удаление потоков.
   Схема рядом показывает, куда уходит трафик. Изменения потоков попадают в Keitaro только по
   кнопке **Push to KT**.

## Термины

- **Поток** — правило внутри кампании Keitaro, которое решает, куда отправить посетителя.
- **Перехватывающий поток** — забирает посетителей, подходящих под его фильтры (например, из
  выбранных стран), раньше остальных потоков и отправляет их на редирект.
- **Фильтр** — условие потока, например «страна — DE или AT»: подходит посетитель из любой
  страны списка.
- **Обычный поток** — отправляет посетителей на офферы в заданных долях.
- **Оффер** — страница, на которую поток отправляет посетителя.
- **Доля** — процент трафика потока, который получает оффер. Сумма долей в потоке — 100 %.
- **Черновик** — изменения потока, которые видны только здесь и ещё не отправлены в Keitaro.
- **Push to KT** — публикация черновиков всех потоков кампании в Keitaro одной пачкой.
