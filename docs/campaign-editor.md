# Редактор кампании

Открывается из списка кампаний или сразу после создания кампании. Слева — параметры, в середине —
потоки, справа — схема.

- **Параметры** (название, домен, группа, источник) сохраняются кнопкой **Сохранить** сразу в
  Keitaro.
- **Схема** показывает, куда уходит трафик: потоки в порядке проверки Keitaro, с учётом
  неопубликованных изменений. На узких экранах схема скрыта.
- В шапке: значок ↗ открывает кампанию в Keitaro, **Обновить** подтягивает изменения из Keitaro,
  **Удалить** отправляет кампанию в архив.

## Потоки

- **Обычный поток** — название и таблица офферов с долями. Название правится прямо в заголовке.
- **Перехватывающий** и остальные потоки показываются только заголовком, их можно лишь удалить.
- Удалённый поток удаляется и в Keitaro.

## Офферы

| Действие            | Что происходит                                                         |
|---------------------|------------------------------------------------------------------------|
| **Add**             | Оффер добавляется в поток, доли пересчитываются                         |
| **Remove**          | Оффер становится серым и уходит вниз списка, его доля — 0 %             |
| **Bring Back**      | Удалённый оффер возвращается, доли пересчитываются                      |
| **×** у серого оффера | Строка убирается из списка насовсем                                   |
| 📌 рядом с долей    | Доля закрепляется и больше не меняется при пересчётах                   |

Доли считаются так: удалённые офферы получают 0 %, закреплённые сохраняют свою долю, остаток
делится поровну между остальными (лишний процент — первым в списке).

## Публикация

Все изменения потоков сначала копятся здесь, а в Keitaro ничего не меняется. Когда есть
неопубликованные изменения, раздел «Потоки» выделен рамкой, а в его заголовке появляются кнопки:

- **Push to KT** — отправляет изменения всех потоков в Keitaro одной пачкой.
- **Cancel** — отбрасывает все неопубликованные изменения.

Push to KT недоступен, пока в каком-то потоке есть проблема — например, удалены все офферы или
освободившуюся долю некому отдать (все остальные офферы закреплены). Проблема написана под
потоком.

Если поток тем временем изменили в Keitaro, публикация блокируется, чтобы не затереть чужие
правки. Кнопка **Взять версию из Keitaro** под потоком отбрасывает ваши правки и показывает
актуальное состояние.
