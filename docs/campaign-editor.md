# Редактор кампании

Редактор открывается из списка кампаний и показывает потоки выбранной кампании из Keitaro.

## Потоки

Потоки делятся на два вида:

- **С офферами** — показываются таблицей: оффер, доля, действия. Их можно редактировать.
- **Остальные** (например, редирект на Google) — показываются только названием. Их содержимое
  редактор не разбирает и не меняет.

## Работа с офферами

Все изменения сначала копятся на нашей стороне. Поток с такими изменениями подсвечивается, а в
Keitaro до нажатия **Push to KT** ничего не меняется. Доли офферов при этом сразу
пересчитываются на экране.

| Действие                | Как                                                    | Что происходит                                                         |
|-------------------------|--------------------------------------------------------|------------------------------------------------------------------------|
| **Добавить оффер**      | Найти оффер по ID или названию под таблицей → **Add**  | Оффер появляется в списке, доли пересчитываются                        |
| **Удалить оффер**       | **Remove** у оффера                                    | Оффер становится серым, его доля — 0 %, вместо Remove появляется **Bring Back**; доли остальных пересчитываются |
| **Вернуть оффер**       | **Bring Back** у серого оффера                         | Оффер снова активен, доли пересчитываются                              |
| **Закрепить долю**      | Значок булавки рядом с долей                           | Доля этого оффера больше не меняется при пересчётах. Повторный клик снимает закрепление |
| **Опубликовать**        | **Push to KT**                                         | Изменения уходят в Keitaro, подсветка снимается                        |
| **Отменить**            | **Cancel**                                             | Все неопубликованные изменения потока отбрасываются (в том числе добавленные офферы), подсветка снимается |

После публикации удалённые офферы отвязываются от потока в Keitaro, но в обёртке остаются в
списке серыми со статусом **Removed** — их можно вернуть кнопкой Bring Back.

## Как пересчитываются доли

- Удалённые офферы получают 0 %.
- Закреплённые офферы сохраняют свою долю.
- Остаток делится поровну между остальными активными офферами. Если ровно не делится, лишний
  процент получают первые офферы в списке.

Примеры:

| Было                          | Действие      | Стало                              |
|-------------------------------|---------------|------------------------------------|
| A 34 %, B 33 %, C 33 %        | Добавить D    | A 25 %, B 25 %, C 25 %, D 25 %     |
| A 34 % 📌, B 33 %, C 33 %      | Добавить D    | A 34 % 📌, B 22 %, C 22 %, D 22 %   |
| A 34 % 📌, B 22 %, C 22 %, D 22 % | Удалить C | A 34 % 📌, B 33 %, C 0 %, D 33 %    |

📌 — закреплённая доля.

## Когда Push to KT недоступен

В двух случаях кнопка неактивна, а под таблицей потока написано, в чём проблема:

- **Удалены все офферы.** Верните оффер кнопкой Bring Back или добавьте новый.
- **Освободившуюся долю некому отдать.** Так бывает, если удалить оффер, когда все остальные
  закреплены: A 50 % 📌, B 30 % 📌, C 20 % → удалить C → A 50 % 📌, B 30 % 📌, и 20 % трафика
  никому не достались. Снимите закрепление с одного из офферов (он заберёт свободные 20 %),
  верните C или добавьте новый оффер.

## Изменения, сделанные в Keitaro

Офферы можно менять и напрямую в Keitaro. При следующем открытии редактора или по кнопке
«Обновить» обёртка подтянет изменения:

- оффер, удалённый в Keitaro, отображается серым со статусом **Removed** и кнопкой Bring Back;
- оффер, добавленный в Keitaro, появляется в списке;
- доли берутся из Keitaro.

Если поток изменили в Keitaro, пока в обёртке есть неопубликованные изменения, публикация
блокируется, чтобы не затереть чужие правки. Нажмите **Cancel**, чтобы увидеть актуальное
состояние, и повторите свои изменения.
